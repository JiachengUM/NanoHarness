# svw_afc 环节0提取产物

此目录存放环节0（输入预处理）的输出文件：

## 输出文件清单

| 文件 | 说明 |
|------|------|
| `extracted_tag_hints.json` | 从原始文件提取的标签线索 |
| `extracted_cases_raw.json` | 已有用例（已标准化格式） |
| `extracted_requirements.md` | 需求描述汇总 |
| `extraction_report.md` | 提取过程报告 |

## 用途

这些提取产物将作为环节1（构建标签树）的输入参考：
- 标签线索辅助增量识别
- 已有case辅助风格参考和场景灵感
- 需求描述补充需求增量
