# GenericEval 🌐

> **One Framework for All Your LLM Evaluations**

Stop building custom eval scripts for every new task.  
GenericEval is a **universal evaluation platform** for generative AI — whether you're working on text classification, image captioning, question answering, or agent reasoning.

---

## 🎯 Why GenericEval?

You shouldn’t need a new tool every time you:

- Change your model’s output format  
- Add a new benchmark dataset  
- Switch from accuracy to custom metrics  
- Compare multiple annotation sources  

**GenericEval handles it all with one consistent system.**

---

## ✨ What Makes It Different?

### 🔁 **Truly Task-Agnostic**

Define your input and output structure once — GenericEval stores, tracks, and evaluates **any structured prediction**, no matter how complex.

### 📦 **End-to-End Traceability**

From raw input → model output → human annotation → metric score, every piece is linked and auditable.

### 🚀 **Built for Real Workflows**

- Run evaluations at scale  
- Compare model versions side-by-side  
- Share results across your team  
- Never lose context again

---

## 💡 The Philosophy

> **“Generic doesn’t mean vague — it means flexible enough to fit your work, not force you into ours.”**

We believe evaluation should **adapt to your task**, not the other way around.
