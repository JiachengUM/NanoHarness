# 工具测试样例生成器

本技能用于为AI工具调用系统生成全面的测试样例，支持多种难度等级和场景组合。

## 核心功能

### 1. 样例生成能力
- **基础样例生成**：每个工具15条基础测试样例
- **超高难度场景**：每个工具20条多意图场景
  - 5条明确意图组合
  - 15条模糊意图场景
- **场景组合分析**：自动识别和标注工具的场景组合类型

### 2. 输出格式

生成的CSV文件包含以下字段：

```csv
工具名称,工具用途简述,工具详情,场景组合,query,query难易程度
```

**字段说明**：
- **工具名称**：工具的唯一标识符
- **工具用途简述**：工具的主要功能概述
- **工具详情**：工具的详细功能描述
- **场景组合**：工具支持的场景类型组合（新增字段）
- **query**：测试查询语句
- **query难易程度**：难度等级（低/中/高/超高-明确/超高-模糊）

### 3. 场景组合分类

根据工具描述自动识别并标注场景组合类型：

#### 单场景工具
- **控制型**：car_control, media, s2s
- **查询型**：weather, info_search, music_search, search_poi, driving_perception, vehicle_manual
- **任务型**：task_master, memory
- **服务型**：jietingche, etalk, restaurant_reservation, coffee_delivery
- **导航型**：route_planner

#### 多场景组合
- **控制+查询**：支持控制和查询双重功能
- **导航+POI**：导航与位置服务组合
- **媒体+娱乐**：音乐、播客、有声书等组合
- **服务+任务**：服务调用与任务管理组合
- **感知+控制**：环境感知与车辆控制组合

### 4. 难度等级定义

| 难度等级 | 特征描述 | 示例 |
|---------|---------|------|
| **低** | 单一明确操作，无歧义 | "把空调调到25度" |
| **中** | 需要参数组合或简单推理 | "附近有没有评分4分以上的火锅店" |
| **高** | 多参数约束，复杂筛选 | "找一下古美评分4.5分以上环境不错有包厢人均100以内的西餐厅" |
| **超高-明确** | 多个明确意图的组合 | "把空调调到25度同时打开座椅加热并关闭所有车窗" |
| **超高-模糊** | 模糊表达，需要上下文理解 | "我有点冷，帮我调一下" |

## 使用方法

### 输入要求
提供工具描述，格式如下：
```
工具名称：<tool_name>
工具描述：<tool_describe>
参数：<param_description>
约束条件：<constraints>（可选）
示例query：<example_queries>
```

### 输出内容
1. **基础样例**（15条/工具）
   - 低难度：5条
   - 中难度：5条
   - 高难度：5条

2. **超高难度样例**（20条/工具）
   - 明确意图：5条
   - 模糊意图：15条

3. **场景组合分析**
   - 自动识别工具的场景类型
   - 标注场景组合特征
   - 生成场景组合字段内容

## 场景组合标注规则

### 单场景标注
```
场景组合 = "单场景-<场景类型>"
```
示例：
- car_control: "单场景-控制型"
- weather: "单场景-查询型"
- task_master: "单场景-任务型"

### 多场景标注
```
场景组合 = "<场景1>+<场景2>+..."
```
示例：
- route_planner: "导航+POI+查询"
- media: "控制+播放+查询"

### 特殊场景标注
- **条件触发**：task_master的条件任务
- **多轮交互**：memory的记忆管理
- **跨域组合**：涉及多个功能域的工具

## 生成流程

1. **解析工具描述**
   - 提取工具名称、用途、详情
   - 识别工具类型和功能域

2. **场景组合分析**
   - 分析工具支持的场景类型
   - 确定场景组合标注

3. **生成基础样例**
   - 从工具描述中提取示例query
   - 补充不同难度的测试样例

4. **生成超高难度样例**
   - 创建多意图明确组合
   - 创建模糊意图场景

5. **输出CSV文件**
   - 包含所有字段
   - 场景组合字段已填充

```csv
car_control,车辆控制系统,支持空调、座椅、门窗、灯光、导航、媒体等车辆功能的控制,单场景-控制型,我有点冷，帮我调一下,超高-模糊
```

## 注意事项

1. **场景组合准确性**：根据工具描述准确识别场景类型
2. **样例多样性**：确保样例覆盖工具的主要功能点
3. **难度分布合理**：各难度等级样例数量均衡
4. **模糊意图真实性**：超高-模糊样例应符合真实用户表达习惯
5. **CSV格式规范**：确保输出文件格式正确，字段完整

## 扩展能力

- 支持自定义样例数量
- 支持指定难度分布
- 支持特定场景组合生成
- 支持批量工具处理
- 支持样例去重和验证
