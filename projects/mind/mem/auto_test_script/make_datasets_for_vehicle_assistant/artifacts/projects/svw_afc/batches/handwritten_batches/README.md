# svw_afc 手写批次

此目录存放环节4的手写用例批次文件。

## 命名规范

批次文件命名：`batch_<序号>_<日期>_<描述>.json`

例如：
- `batch_01_20250610_initial.json`
- `batch_02_20250612_navigation.json`

## 内容格式

每个批次文件是一个 JSON 数组，包含 15-25 条用例，遵循 `vehicle_assistant_cases.json` 的 schema。

## 工作流程

1. 环节4：编写一批用例（约20条）→ 保存为批次文件
2. 环节5：审计本批次 → 输出审计报告
3. 环节6：修复本批次 → 保存修复后版本
4. 合并入总集 → 检查覆盖率 → 不够就再写一批
