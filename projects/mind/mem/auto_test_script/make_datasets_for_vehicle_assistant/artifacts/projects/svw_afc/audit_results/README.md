# svw_afc 审计结果

此目录存放环节5（质量审计）的输出报告。

## 命名规范

审计报告命名：`audit_<批次名>_<日期>.json`

例如：
- `audit_batch_01_20250610.json`
- `audit_batch_02_20250612.json`

## 内容

审计报告包含对每条例的审核结果：
- 是否通过
- 问题列表（如有）
- 修复建议（如有）

## 审核原则

基础审核原则：`skills/_shared_case_audit_principles.md`（基础）→ `<P>/tag_tree/case_audit_supplements.md`（项目覆盖，优先）
