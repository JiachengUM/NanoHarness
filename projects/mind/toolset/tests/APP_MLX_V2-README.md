# Qwen ASR/TTS Streaming API - Improved VAD

## 概述

本脚本提供基于 MLX 的语音识别（ASR）和语音合成（TTS）功能，包含改进的语音活动检测（VAD）系统。脚本实现了以下核心功能：

- 实时语音识别（ASR）：基于 Qwen3-ASR-0.6B-8bit 模型
- 语音合成（TTS）：基于 Qwen3-TTS-12Hz-1.7B-Base-bf16 模型
- 持续监听模式：支持麦克风常亮的语音交互
- 智能 VAD：自适应噪声地板和动态阈值

## 快速开始

```bash
# 安装依赖
pip install fastapi uvicorn numpy soundfile sounddevice mlx-audio

# 运行服务
python app_mlx_v2.py
```

服务将在 `http://localhost:8000` 启动。

## API 接口

### 启动持续监听
```
POST /asr/always-on/start
```

### 停止持续监听
```
POST /asr/always-on/stop
```

### 查询监听状态
```
GET /asr/always-on/status
```

### 获取识别结果
```
GET /asr/always-on/result
```

### TTS 语音合成
```
POST /tts/generate
Content-Type: application/json

{"text": "你要合成的文本"}
```

### 卸载模型（释放内存）
```
POST /models/unload
```

## 可调整参数详解

脚本中的 `Config` 类包含所有可调整参数，以下按功能分类说明：

### ASR 语音识别参数

| 参数名 | 默认值 | 可调范围 | 作用说明 | 体感影响 |
|--------|--------|----------|----------|----------|
| `SAMPLERATE` | 16000 | 8000-48000 | 音频采样率 | 影响识别精度和模型兼容性，通常保持默认 |
| `BUFFER_DURATION` | 15.0 | 5.0-60.0 | 音频缓冲区时长（秒） | 决定单次识别的最大语音长度，过长会延迟，过短会截断长句 |
| `SILENCE_THRESHOLD` | 0.5 | 0.1-1.0 | 能量阈值系数 | 控制静音检测灵敏度，值越小越敏感 |
| `SILENCE_DURATION` | 3.0 | 1.0-10.0 | 语音结束后的静音等待时间（秒） | 决定用户说完后多久开始识别，过短可能截断，过长导致延迟 |

### VAD 语音活动检测参数

| 参数名 | 默认值 | 可调范围 | 作用说明 | 体感影响 |
|--------|--------|----------|----------|----------|
| `VAD_AGGRESSIVENESS` | 1 | 0-4 | VAD检测激进程度 | 0最保守（易漏检），4最激进（易误触发） |
| `VAD_MIN_SPEECH_DURATION` | 0.3 | 0.1-1.0 | 最小语音片段时长（秒） | 过滤短促的噪音，值太小易误触发，太大可能丢失短语音 |
| `VAD_MAX_SILENCE_BEFORE_SPEECH` | 0.5 | 0.1-2.0 | 语音前保留的静音时长（秒） | 确保捕获语音开头，值太小可能丢失开头，太大增加延迟 |
| `VAD_MAX_SILENCE_AFTER_SPEECH` | 1.0 | 0.5-3.0 | 语音结束后的静音容忍时长（秒） | 适应说话停顿，值太小易中断，太大延迟结束 |

### TTS 语音合成参数

| 参数名 | 默认值 | 可调范围 | 作用说明 | 体感影响 |
|--------|--------|----------|----------|----------|
| `TTS_SPEED` | 1 | 0.5-2.0 | 语音合成速度 | 调整语速，小于1变慢，大于1变快 |
| `TTS_MAX_TOKENS` | 2048 | 512-8192 | 单次合成最大token数 | 限制单次合成文本长度，避免超长文本导致内存问题 |
| `TTS_STREAMING_INTERVAL` | 0.5 | 0.1-2.0 | 流式合成间隔（秒） | 控制流式输出的chunk大小，值越小延迟越低但开销越大 |
| `TTS_TEMPERATURE` | 0.3 | 0.0-1.0 | 生成温度 | 控制语音多样性，值越高语音变化越大，可能不稳定 |
| `TTS_TOP_P` | 0.7 | 0.1-1.0 | 核采样概率阈值 | 控制生成的多样性，值越小越保守 |
| `TTS_TOP_K` | 50 | 10-200 | 核采样候选数 | 限制每次选择的候选token数量，值越小越确定 |

### 系统控制参数

| 参数名 | 默认值 | 可调范围 | 作用说明 |
|--------|--------|----------|----------|
| `VERBOSE` | True | True/False | 是否输出详细日志 |
| `MICROPHONE_ALWAYS_ON` | False | True/False | 麦克风常亮模式开关 |

## 关键参数深度解析

### 1. VAD_AGGRESSIVENESS（VAD激进程度）

**调整范围**: 0-4

**作用原理**:
- **0（最保守）**: 只检测清晰、连续的语音，适合安静环境
- **1（默认）**: 平衡模式，适合普通办公室环境
- **2-3（中等激进）**: 适合有一定背景噪音的环境
- **4（最激进）**: 检测微弱语音，适合嘈杂环境但容易误触发

**体感影响**:
- 设置过低（0-1）: 在嘈杂环境下可能漏检用户语音，用户感觉"系统没听到"
- 设置过高（3-4）: 容易把环境噪音识别为语音，用户感觉"系统自己在说话"

**推荐配置**:
- 安静办公室: 0-1
- 普通环境: 1-2
- 车载/公共场所: 2-3

---

### 2. SILENCE_DURATION（静音等待时间）

**调整范围**: 1.0-10.0 秒

**作用原理**: 检测到语音结束后，等待多长时间静音才判定为说话结束

**体感影响**:
- **设置过短（<2秒）**: 用户说话停顿或思考时容易被截断，感觉"系统打断我说话"
- **设置过长（>5秒）**: 用户说完后需要等待很久才能听到回应，感觉"系统反应慢"

**推荐配置**:
- 快速响应场景（如命令控制）: 1.0-2.0
- 正常对话场景: 2.0-3.0
- 长时间演讲场景: 3.0-5.0

---

### 3. TTS_SPEED（语速）

**调整范围**: 0.5-2.0

**作用原理**: 控制合成语音的播放速度

**体感影响**:
- **设置过慢（<0.8）**: 用户感觉"机器人说话太慢，不耐烦"
- **设置过快（>1.5）**: 语音变得急促，可能听不懂，感觉"机器人说话太快"

**推荐配置**:
- 正常对话: 0.9-1.1
- 播报场景（如导航）: 1.1-1.3
- 儿童/老人使用: 0.8-0.9

---

### 4. TTS_TEMPERATURE（温度参数）

**调整范围**: 0.0-1.0

**作用原理**: 控制语音生成的随机性

**体感影响**:
- **设置过低（<0.2）**: 语音过于机械、单调，缺乏自然语调变化
- **设置过高（>0.7）**: 语音可能出现不稳定、发音错误或奇怪的语调

**推荐配置**:
- 追求稳定清晰: 0.2-0.4
- 追求自然流畅: 0.4-0.6
- 接受一定随机性: 0.6-0.8

---

### 5. VAD_MAX_SILENCE_BEFORE_SPEECH（语音前静音保留）

**调整范围**: 0.1-2.0 秒

**作用原理**: 保存检测到语音之前的静音片段，确保语音开头不被截断

**体感影响**:
- **设置过小（<0.3）**: 可能丢失语音开头的部分内容，用户感觉"系统没听清开头"
- **设置过大（>1.0）**: 会增加识别延迟，且可能包含不必要的环境噪音

**推荐配置**:
- 快速响应: 0.2-0.4
- 正常对话: 0.4-0.6
- 远距离拾音: 0.6-1.0

## 常见问题与参数调整建议

### 问题1: 系统经常误触发，把环境噪音当成语音

**可能原因**: VAD过于激进，或能量阈值过低

**调整方案**:
```python
Config.VAD_AGGRESSIVENESS = 0  # 降低激进程度
Config.VAD_MIN_SPEECH_DURATION = 0.5  # 增加最小语音时长
```

### 问题2: 说话时经常被截断

**可能原因**: 静音等待时间过短，或VAD提前判定语音结束

**调整方案**:
```python
Config.SILENCE_DURATION = 4.0  # 增加静音等待时间
Config.VAD_MAX_SILENCE_AFTER_SPEECH = 1.5  # 增加语音后静音容忍
```

### 问题3: 说完话后系统反应太慢

**可能原因**: 静音等待时间过长

**调整方案**:
```python
Config.SILENCE_DURATION = 2.0  # 减少静音等待时间
```

### 问题4: TTS语音不自然，机械感强

**可能原因**: 温度参数过低，语音缺乏变化

**调整方案**:
```python
Config.TTS_TEMPERATURE = 0.5  # 适当提高温度
Config.TTS_TOP_P = 0.8  # 增加多样性
```

### 问题5: TTS语音不稳定，偶尔发音错误

**可能原因**: 温度参数过高

**调整方案**:
```python
Config.TTS_TEMPERATURE = 0.3  # 降低温度
Config.TTS_TOP_K = 30  # 减少候选数，增加稳定性
```
