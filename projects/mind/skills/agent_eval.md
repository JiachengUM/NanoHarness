# Agent 结果评测分析技能

## 功能描述
本技能用于分析基于React循环调用工具执行的结果文件（CSV格式），并生成详细的评测报告，从调用工具准确度、合理性、上下文理解能力、推理能力等维度进行分析。

## 输入参数
- **file_path**：CSV、JSON、Excel文件路径，包含用户输入、工具输入输出、Agent输出等数据
- **output_report_path**：评测报告输出路径，格式为Markdown（默认：根目录下的评测报告文件）
- **threshold**：分数阈值，低于此分数的记录需要详细展示（默认：9分，满分10分）

## 执行步骤

### 1. 数据读取与验证
- 读取文件内容，确认数据记录数
- 验证读取的记录数与文件实际记录数是否一致，确保数据完整性
- 检查必要字段是否存在：query、message、tool_input、tool_output

### 2. 数据解析
- 解析每条记录的用户输入（query字段）
- 解析工具调用（tool_input字段）
- 解析工具输出（tool_output字段）
- **重点**：从message字段中提取assistant的响应内容

### 3. 维度评测（满分10分）

#### 3.1 调用工具准确度（0-10分）
**评测要点**：
- 工具选择是否正确（websearch、media、car_control等）
- 搜索词是否精准、符合用户意图
- 是否避免了基于假设的搜索（如假设用户在上海）
- 是否避免了使用占位符进行搜索（如"[您的姓氏]"）

**扣分标准**：
- 用户明确要求搜索但未调用工具：-5分
- 搜索词基于假设（如假设用户地域）：-5分
- 搜索词包含占位符：-3分
- 搜索时间范围不准确：-1分

#### 3.2 合理性（0-10分）
**评测要点**：
- 响应内容是否符合用户需求场景
- 工具返回空结果时是否妥善处理
- 是否确认执行了用户要求的操作（如播放、导航）
- 响应是否提供了有用的建议或替代方案

**扣分标准**：
- 工具返回空结果但响应未妥善处理：-3分
- 用户要求操作但响应未确认：-2分
- 响应内容与用户需求不匹配：-2分

#### 3.3 上下文理解能力（0-10分）
**评测要点**：
- 是否识别并处理模糊指代（如"这地方"、"我老家"、"这首歌"）
- 是否询问用户关键信息（如地域、年龄段、偏好类型）
- 是否理解用户的多轮对话上下文

**扣分标准**：
- 用户使用模糊指代但未要求澄清：-3分
- 未询问用户关键信息就执行操作：-2分
- 未考虑用户上下文直接响应：-2分

#### 3.4 推理能力（0-10分）
**评测要点**：
- 基于工具返回结果的推理过程是否合理
- 响应内容是否充分（长度、结构）
- 是否提供了建设性建议
- 响应结构是否清晰（使用标题、列表等）

**扣分标准**：
- 工具返回空结果但响应过于简短（<20字）：-2分
- 响应缺乏建设性建议：-1分
- 工具返回结果但响应过于简短（<50字）：-2分
- 响应结构不够清晰：-1分

### 4. 问题类型识别

#### 4.1 工具准确度问题
- 搜索词假设用户地域
- 使用占位符进行搜索
- 未调用必要工具
- 搜索词不符合用户意图

#### 4.2 上下文理解问题
- 模糊指代未澄清
- 未询问关键信息
- 未考虑用户上下文

#### 4.3 推理能力问题
- 响应过于简短
- 缺乏建设性建议
- 响应结构不清晰

#### 4.4 合理性问题
- 空结果处理不当
- 操作未确认
- 响应与需求不匹配

### 5. 报告生成

#### 5.1 数据概览
- 数据来源路径
- 记录总数
- 评测维度说明
- 评测标准说明

#### 5.2 评测结果总览
- 各维度平均分统计表
- 分数分布统计
- 问题类型分布统计

#### 5.3 详细评测分析
**仅包含低于阈值的记录**，每条记录包含：
- 记录ID
- 用户输入
- 各维度得分
- 问题分析
- 改进建议

#### 5.4 优秀案例展示
**展示满分记录**，总结优秀特征：
- 工具调用准确
- 响应内容丰富
- 结构清晰
- 符合用户需求
- 多维度覆盖

#### 5.5 总结与建议
- 整体表现评估
- 主要问题总结
- 改进建议（分优先级）
- 后续优化方向（短期、中期、长期）

### 提取Assistant响应
```python
def extract_assistant_message(message_str):
    """从message字段中提取assistant的响应内容"""
    try:
        messages = eval(message_str)
        for msg in messages:
            if 'assistant' in msg:
                return msg['assistant']
        return ""
    except:
        return ""
```

### 文件格式处理
- 处理CSV文件时，注意编码问题（建议使用utf-8-sig）
- 处理特殊字符，避免解析错误
- 对于空记录或格式不正确的记录，应进行适当处理

## 评测标准参考

### 满分案例特征
1. **工具调用准确**：搜索词精准，符合用户意图
2. **响应内容丰富**：充分利用工具返回的结果，提供详细信息
3. **结构清晰**：使用标题、列表等方式组织内容
4. **符合用户需求**：响应内容与用户查询高度相关
5. **多维度覆盖**：涵盖用户可能感兴趣的多个方面

### 常见问题示例

#### 问题1：地域假设
```
用户输入: 市里最近有啥新鲜事
错误工具调用: websearch搜索"上海市近期新鲜事"
正确做法: 先询问用户所在城市，再进行搜索
```

#### 问题2：模糊指代未澄清
```
用户输入: 这首歌副歌有多少字
错误响应: 未查询到相关信息
正确响应: 请问您指的是哪首歌呢？告诉我歌曲名称，我帮您查询～
```

#### 问题3：空结果处理不当
```
用户输入: 最近科技圈有什么值得关注的事
工具输出: 未找到结果
错误响应: 未查询到相关信息
正确响应: 未查询到相关信息。建议您：
1. 尝试搜索"科技新闻"或"科技动态"
2. 扩大时间范围，如搜索"近期科技新闻"
3. 指定具体领域，如"AI科技新闻"
```
