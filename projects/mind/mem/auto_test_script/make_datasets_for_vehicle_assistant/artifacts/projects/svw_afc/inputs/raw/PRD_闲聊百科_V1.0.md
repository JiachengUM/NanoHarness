# 四、需求背景

车载大模型场景中，无论是根据产品预期还是根据当前现有的数据看，闲聊百科都是用户使用量最大的。

以上，在与大模型进行对话聊天过程中，为了保证良好的闲聊百科对话体验，本篇文档需要对闲聊百科的输出上通过场景分类进行明确的说明。包括在聊天中能够记住自己车辆助手的身份，并且符合车辆助手的设定、车企的敏感信息要求以及车企功能相关信息要求，提供正确或合适的内容回复。

## 闲聊

闲聊百科该功能需要结合模型的设定来进行，包括基础设定以及个性化人设的设定。以下内容仅重在说明逻辑和要求，不包含具体人设风格的内容。

基础设定按照默认通用设定进行。具体构建人设prompt所需的信息要求在【AI助理\-个性化人设】中进行详细说明。

闲聊百科支持的上下文轮数按照大模型基础能力的5轮为准。

对于意图为chat（闲聊）的Query，模型也会进行自决策是直接输出还是进行网络搜索后再回复。

如上，闲聊和人设设定相关，在闲聊的过程中，需要对以下内容进行稳定控制，控制方式分为prompt提示词及知识库\(FAQ\)人工干预：

1. 人设设定一致性

2. 回复内容适当性

    1. 回复内容需要和Query有对应性；

    2. 回复内容需要符合道德或法律层面的正向性；

## 网络信息搜索

闲聊和百科问题里除了一些模型训练时间范围内的通用知识外，还需要有一些实时性或者可能会收到模型回复幻觉影响类的问题的回复。这部分回复就依赖进行联网搜索。

当意图识别为broswing（联网）时，调用头条新闻插件进行网络信息检索及回复。

联网意图中的模型回复提示词与闲聊提示词非同一套，因为闲聊的人设提示词会对回复内容的准确性造成影响，所以一般联网意图中的回复提示词中重点是对输出长度的限制，而不会对模型回复内容风格做限制。

## 负向舆情处理（标准能力\+车厂定制）

负向舆情包括一些通用风险及车厂品牌形象相关的内容。通用风险已在[大模型基础能力](https://s9z5augmk9.feishu.cn/docx/LhOId3hPaofKg7xcR5ScB27wntg#share-VHvXdb53MoOphtxOccDc57uun9A)文档中进行说明，车厂相关风险在下方做具体的类目说明。该类负向舆情的内容同样由【风险】意图进行处理，通过提示词和FAQ干预的方式进行管控。

对于大众相关的负向舆情或者正向回复，如有标准化话术要求，需要大众提供相关泛化Query及回复内容。

当前对于车厂相关的负面内容分类情况如下：

|类别|说明|示例Query|
|---|---|---|

## 正向推荐处理（车厂定制）

除了负向的内容处理外，一些正向/中性的用户Query输入，也需要在回复时考虑到车厂企业形象，给予正向引导。

对于大众相关的正向推荐，需要大众提供相关的车辆知识库，包含。

### 推荐类

对于推荐类的Query，会识别为【车推荐】意图，在该意图中，将按照以下回复策略进行回复。

- **回复策略**：

    - 当用户直接让推荐【品牌】的车且在Query中未明确说明其他品牌或车型时，优先推荐【当前品牌】的车；

    - 当用户让推荐【品牌】的车且已在Query中明确说明其他品牌或车型时，则推荐对应品牌或车型的车

### 对比类

对于对比类的Query，会识别为【车推荐】意图，在该意图中，将按照以下回复策略进行回复。

- **回复策略**：

    - 当用户在比较其他品牌的车和【当前品牌】时，优先推荐【当前品牌】的车，但需保证**不拉踩其他品牌**的基本原则，以防有法律风险；

    - 当用户在比较【当前品牌】的多个车型时，需站在客观角度，保证不拉踩任一车型的基本原则，进行适宜的回复；

### 评价类

对于评价类的Query，负向评价会识别为【风险】意图，通过风险意图中的管控策略进行回复；正向评价的建议意图识别为闲聊，按照闲聊的提示词约束进行回复。

- **回复策略**：当用户对【当前品牌/车型】（包括其他品牌或车型）进行评价类的表述时，需要对于评价的正负性提供适宜的回复；
