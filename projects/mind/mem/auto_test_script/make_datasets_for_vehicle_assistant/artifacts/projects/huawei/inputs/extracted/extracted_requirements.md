## 1. 中枢落域

### 1.1 五个中枢域 + 大模型

- 传统垂域：车控/导航/媒体/电话/系统设置等高频车载能力（由「车厂A语音指令泛化V2.0」提供详细二级意图）
- 出行助手：地点推荐、行程规划、导航去推荐地
- 搜索助手：新闻、百科、长尾小技能
- 用车助手：车机/车辆/交规保险等用车知识（车书）
- 趣味助手：闲聊
- 大模型句式：「用大模型」类发话一律走大模型

### 1.2 出行助手 vs 导航传统垂域 仲裁策略

来源：docx + 智能中枢仲裁规则.xlsx#出行助手。按优先级顺序匹配：

1. **第一优先级（导航垂类）**：「导航去xx」「到xx的路线」「我想去xx」「去xx」等明确导航/路线规划意图。例：导航去北京天安门、到广州塔的路线。
2. **第二优先级**：判断用户搜索的<地点类型>：
   - 直接指定具体 POI 地点/品牌词/省市区 → 导航垂类。例：搜索天坛公园、搜索天安云谷附近的瑞幸咖啡。
   - 搜索固定地点类型（充电桩/加油站/停车场/卫生间/金融保险/公共设施/交通运输仓储）→ 导航垂类。例：搜索国贸附近的加油站。
   - 除上述类型外的地点推荐（湘菜馆/咖啡店/景点/美食/公园等）、含限定条件、模糊泛化地点搜索 → 出行助手。例：国贸附近有啥好吃的、中关村地铁站附近有啥适合聚会的地方。
3. **第三优先级（出行助手）**：隐晦需求表达。例：我想给小孩过生日推荐几个地方、我饿了、我想出去玩。
4. **补充规则**：
   - 「导航去XXX(POI地点/品牌词)」统一由导航垂类响应（即使 POI 来自出行助手的推荐结果）。
   - 询问推荐理由/特色/对比 → 出行助手大模型总结。
   - 长途旅游规划/路线推荐 → 出行助手大模型兜底。

> 注意：docx 版仲裁与智能中枢出行助手表在「当前定位附近」上有轻微口径差异（docx 把「当前定位附近地点」判为导航垂类，出行助手表把「附近有啥中餐厅/附近有没有卫生间」等区分得更细）。以智能中枢仲裁规则.xlsx 为准（更具体）。

### 1.3 多轮跨域落域判定

- 大于2轮时，按最后一轮的跨域场景分类。
- 跨域语料含指代/省略/澄清/模糊四种现象。
- 弱多轮下分：意图域延续（不跨域）、意图跨域（显式转移领域）。

## 2. 说法改写任务（传统垂域）

### 2.1 标准化改写

将表述不同但含义相同的语音指令扩展规范为统一格式：
- 口语化表达规范化（空调帮我开开吧 → 开启空调）
- 生僻拗口表达规范化
- ASR 噪声修正
- 同义说法归一

### 2.2 上下文改写（多轮强关联）

- 指代消解（那 = 静安寺）
- 上下文继承（省略信息补全）
- 跨域继承（调高音量 → 继续调高导航音量）
- 一语多意图（体现执行次序）
- 否定意图 / 上下文否定意图
- 模糊意图表达

### 2.3 弱关联多轮改写

- 强多轮：必须依赖前文（含代词如「它」「再来一个」「继续」）→ 本期必须支持。
- 弱多轮：脱离前文语义自洽，领域/槽位可由上轮补充强化 → 本期尝试，不必须支持。

### 2.4 改写标准（交付目标）

- 尽可能贴近客户典型说法
- 符合常理、符合指令式表达（「打开空调」优于「开启空调」但两者都合理）
- 客户下游是自研提槽模型，改写结果供其消费

## 4. 搜索助手

### 4.1 新闻问答仲裁

- 用户发话表明用「喜马拉雅」听新闻 → 传统垂域。
- 其他未说明音源 → 大模型新闻助手。
- 新闻搜索：热点/关键词/类别/地区及组合。
- 新闻信息问答：对特定新闻事件提问。
- 指定新闻播报：第N条/标题关键字/大模型选择。
- 新闻深度解读：背景/角色/观点/时间轴/影响。

### 4.2 百科问答仲裁

- 通用仲裁：现有垂类/智能体优先于百科；出行/新闻/用车 > 大模型百科 > 闲聊。
- 判定两维度：句式（疑问句/陈述句含"介绍一下/对比一下/搜索"/观点性问句）+ 内容（普遍客观事实而非主观感受或操作指令）。
- 意图大类：自然科学/工程技术/医学/社会科学/文化艺术/历史/体育/地理/经济/人物/书籍/影视/游戏/生活/教育/政治/宗教/法律/网络/交通。

### 4.3 长尾小技能

笑话、绕口令、科学计算、单位换算、时间查询（公历/农历/节日/节气）、汇率换算、翻译、古诗、星座、故事。

## 5. 趣味助手（闲聊支持范围）

日常问候、人设询问、情感陪伴、助手状态/主观点询问、投诉抱怨、自定义角色扮演。

## 6. 用车助手（车书等用车知识）

- 车机知识（共通）：系统功能/导航/通话/影音/车机互联/车辆设置/空调设置/系统设置的使用说明。
- 车辆知识：车辆控制/规格/仪表/故障处理/维护保养/驾驶/安全须知/术语解释。
- 交规（违法处罚）/车险知识/车牌归属地/车辆购置租赁/驾驶技巧与安全/语音操作方法。
- 注：电子手册功能划入大模型。

## 7. 出行助手意图规则

- 地点推荐（第一/第二/第三优先级，见 §1.2）
- 导航去推荐地 → 导航垂类
- 询问推荐理由/特色/对比 → 出行助手
- 长途兜底回复（旅游规划/路线推荐）→ 出行助手大模型
