# svw_afc 标签树与打标指南

此目录存放环节1（构建标签树）的产物，是项目核心产物之一：

## 文件清单

| 文件 | 说明 |
|------|------|
| `vehicle_assistant_case_tag_tree.json` | 项目标签树（所有可测能力点的层级定义，唯一事实来源） |
| `vehicle_assistant_case_tagging_guideline.md` | 项目打标指南（含 §2.1 项目写作原则覆盖） |
| `case_audit_supplements.md` | 项目审核原则覆盖（优先于基础审核原则） |

## 用途

- 环节2/4 读此目录写用例
- 环节3 读此目录做场景采样
- 环节5/6/7 读此目录审计、修复、导出

**三者一致性原则**：标签树、打标指南、用例库三者必须保持一致，任何一方的变更都必须同步到另外两方。
