## 验收标准说明

### 1. 推荐歌曲合理性（1-5分）
- **5分**: 合理消费记忆且和对应用户query
- **3分**: 消费合理性欠佳
- **0分**: 不合理消费 or 和用户query不对应

### 2. 回复话术（1-5分）
- **5分**: 除可选项之外均完美达成
  - 表达完整，包含必要元素（歌曲信息等）
  - 在车上有信息量，相对精简的句子
  - 表达了合理的推荐理由
- **3分**: 部分得分点缺失或因可选项扣分
- **0分**: 有多项失分，或者表达人机感强

### 3. 多轮/情景（1-5分）
- **5分**: 5/5，5轮交互体感丰富
  - 在用户标签稀少的阶段，进行合理联想
  - 连续使用时可组合消费不同的用户偏好
- **3分**: 3/5，5轮中3轮体感丰富，2轮重复
- **0分**: 5轮中，推荐内容过度重复
